=== DESCRIPTION ===
보고 있는 페이지의 동영상과 오디오를 저장하세요. YouTube, Shorts, Instagram, Twitch, TikTok, VK, Bilibili, Dailymotion 등 지원. 동영상을 GIF로 변환. 무료, 로컬 처리, 유료 결제 없음, 추적 없음.

VDL - Video Downloader Legal은 열려 있는 페이지에서 재생되는 미디어를 목록으로 보여 주고, 선택한 것을 저장합니다. 모든 작업은 브라우저 안에서 이루어집니다. 외부 서버도, 분석 도구도, 별도 설치 프로그램도 필요 없습니다. 영상과 오디오 병합, TS → MP4 변환은 확장 프로그램 자체 코드로 재인코딩 없이 처리됩니다.

주요 기능
- 동영상 다운로드 — 모든 사이트의 직접 파일, HLS(m3u8), DASH(mpd) 스트림 지원. 화질을 고르면 분리된 오디오 트랙이 하나의 파일로 합쳐집니다.
- 동영상 → GIF — 짧은 동영상(최대 3분)을 브라우저에서 바로 애니메이션 GIF로 변환. 너비 640 / 480 / 320 / 240px, 5~15 FPS, 예상 크기를 미리 표시.
- 변환기 — 컴퓨터의 동영상·오디오 파일로 GIF(시작~끝 구간, 너비, FPS)를 만들고 흰 띠, 영상 위 텍스트, 디모티베이터 형식의 자막을 선택적으로 추가할 수 있으며 실시간 미리보기를 제공합니다. MP3, PNG 프레임, TS → MP4 / MKV, 조각난 MP4 → MP4도 재인코딩 없이 변환. 파일은 브라우저 밖으로 나가지 않습니다.
- YouTube 및 YouTube Shorts — 형식(MP4, WEBM, AV1)과 해상도 선택, 오디오는 MP3·M4A·WEBM, 영상과 오디오를 하나의 파일로.
- 라이브 스트림 — Twitch 등 HLS 라이브를 중지를 누를 때까지 녹화, 플레이어에서 YouTube 라이브 녹화(베타).
- TS → MP4 — MPEG-TS 스트림은 기본적으로 일반 MP4로 저장(재인코딩 없음), MKV와 TS도 선택 가능.
- TikTok — 화면에 보이는 영상이 제목·커버와 함께 맨 위에, 나머지 피드는 '더보기'에.
- 기타 사이트 — Vimeo, Dailymotion, RuTube, Dzen, Instagram, Facebook, X(Twitter), Bilibili, Canva, OKru, VK 및 일반 스트림 감지로 지원되는 모든 사이트(결과는 페이지가 제공하는 내용에 따라 달라집니다).
- 오디오 다운로드 — MP3(브라우저에서 변환), M4A, WEBM.
- 라이트/다크 테마 — 시스템 설정을 따릅니다. 10개 언어: 영어, 러시아어, 중국어, 스페인어, 힌디어, 프랑스어, 아랍어, 포르투갈어, 독일어, 일본어.
- 편의 기능 — 다운로드 기록, 파일 이름 템플릿, 알림, 단축키 Alt+↓, 컨텍스트 메뉴 항목, 내장 도움말.
- 진단 — 버튼 하나로 로컬 파일(링크 마스킹)을 저장해 버그 신고에 첨부할 수 있습니다. 선택형 디버그 로그(기본값 꺼짐)가 확장 프로그램의 동작을 기록합니다. 자동으로 전송되는 것은 없습니다.
