# Справка · Video Downloader Legal (VDL)

Исходный код: https://github.com/aspidovss/video-downloader-legal

Расширение, которое находит видео и звук на открытой странице и сохраняет их на компьютер. Работает локально: без внешних серверов, без телеметрии, без установки сторонних программ.

## 1. Как пользоваться
1. Откройте страницу с видео и запустите воспроизведение (на некоторых сайтах поток появляется только после старта).
2. Нажмите значок VDL на панели. В списке появятся найденные видео.
3. Выберите тип и качество и нажмите «Скачать». Для звука есть отдельная строка: MP3, M4A или WEBM.
4. Готовые файлы видны в «Истории» (значок часов) и в папке загрузок (значок папки).

Быстрые способы: горячие клавиши (настраиваются в «Настройки → Общие»).

## 2. Что реализовано
- **Прямые файлы** (mp4, webm, mp3 и др.).
- **HLS (m3u8) и DASH (mpd):** выбор качества, отдельная звуковая дорожка, шифрование AES-128, склейка видео и звука в один файл без перекодирования.
- **YouTube:** выбор типа (MP4, WEBM, AV1) и разрешения, скачивание звука (MP3, M4A, WEBM), склейка видео и звука в один файл. Если прямая ссылка недоступна, есть запасной способ: запись из плеера.
- **Прямые эфиры YouTube (бета):** запись из плеера в реальном времени без перезагрузки страницы. Кнопка «Стоп» завершает запись и склеивает видео со звуком в .mp4. Звук отдельно не скачивается.
- **Другие сайты:** Vimeo, Dailymotion, RuTube, Дзен, Instagram, Facebook, X (Twitter), Twitch, TikTok, Bilibili, Canva, OK.ru, VK; остальные сайты через общий перехват потоков. Для части сайтов работа ограничена тем, что отдаёт страница.
- **Эфиры других сайтов (HLS):** запись по кнопке «Записывать», остановка вручную или по лимиту времени.

## 3. Настройки
- **Предпочтения по умолчанию:** качество и тип видео, формат и качество аудио.
- **Общие:** уведомления, история, «Сохранить как», шаблон имени файла ({title} {site} {quality} {date} {time}), минимальный размер файлов, число параллельных загрузок сегментов, лимит записи эфира.
- **Настройки YouTube:** четыре параметра со значком «?» (нажмите — появится пояснение): загрузка по одному куску, добавление cpn, заголовки Origin/Referer/DNT, получение ссылок как у мобильного приложения. Дополнительно: метод получения ссылок, порядок клиентов, их переопределения, режим «только Creative Commons», скорость записи.

## 4. Если что-то не работает
- Включите расширению доступ ко всем сайтам: `about:addons` → VDL → «Разрешения».
- Если ссылок нет, воспользуйтесь записью из плеера.
- Если проблему трудно повторить, включите в настройках «Журнал отладки» (блок «Диагностика»): расширение запишет свои действия; журнал можно посмотреть, скопировать, сохранить в файл или отправить. Результат автодиагностики добавляется в него. Журнал хранится в браузере и сам никуда не уходит.
- Нажмите 🐞: расширение создаст файл диагностики и готовый текст обращения. В файле нет ссылок на видео, cookies и идентификаторов посетителя. Приложите файл к письму или обращению на GitHub.

## 5. Ограничения
- Потоки с DRM (Widevine, FairPlay и др.) не скачиваются и не обходятся.
- YouTube: зашифрованные форматы и потоки SABR не поддерживаются. Токены и подписи не подделываются.
- Скачивайте только то, что вам разрешено сохранять. Соблюдать правила сайтов вы обязаны сами.
- Не поддерживаются: конвертация форматов, пакетная загрузка, плейлисты, субтитры.

## 6. Приватность
Расширение ничего не отправляет разработчику. Данные (история, настройки) хранятся в вашем браузере. Диагностика создаётся только по вашему нажатию и отправляется только вами.

## 8. Используемые компоненты
**Сторонняя библиотека.** Для преобразования звука в MP3 используется **lamejs** 1.2.1 — JavaScript-порт кодировщика LAME.
- Ссылка: https://github.com/zhuker/lamejs (тег `1.2.1`)
- Проект LAME: https://lame.sourceforge.net/
- Лицензия: **LGPL-3.0** (https://www.gnu.org/licenses/lgpl-3.0.html)
- Файл `vendor/lame.js` собран из неизменённых исходников lamejs (`scripts/build-lamejs.mjs` пересобирает его) и может быть заменён другой сборкой, которая предоставляет `lamejs.Mp3Encoder`. Контрольная сумма SHA-256: `f7f74b09d1190d9935e776169dd76c7b66e30db7e2f51b816af88f85a44ed9a8`.
- Библиотека работает локально в браузере и не выполняет сетевых запросов. Без неё MP3 недоступен, остальные форматы работают.

Для работы с видео (разбор потоков и склейка видео со звуком без перекодирования) используется собственный склейщик VDL, `lib/mux.js`.
